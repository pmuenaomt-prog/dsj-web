# DSJ — Distribuidora San José

Sitio web de Distribuidora San José (dsj.cl), ferretería en San Bernardo, Santiago.

## Contenido

- `index.html` — el sitio completo en un solo archivo (estilos, scripts e imágenes incluidos).

## Ver el sitio localmente

Abrir `index.html` con doble clic en cualquier navegador.

## Publicar en Netlify

**Opción manual:** entrar a [app.netlify.com/drop](https://app.netlify.com/drop) y arrastrar `index.html`.

**Opción automática (recomendada):** en Netlify, *Add new site → Import an existing project → GitHub* y elegir este repositorio.
No requiere comando de build; el directorio de publicación es la raíz (`/`).
Desde ahí, cada cambio subido a este repositorio se publica solo.
